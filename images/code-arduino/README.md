# Code Arduino - Screenshots

Ce dossier contient les captures d'écran des codes Arduino pour les projets.

## Structure

Créer un dossier pour chaque projet avec un nom simple (sans espaces, en minuscules):

```
images/code-arduino/
├── README.md
├── nom-du-projet-1/
│   ├── code-01.png
│   ├── code-02.png
│   └── ...
└── nom-du-projet-2/
    ├── code-01.png
    └── ...
```

## Instructions

1. Pour chaque projet, créer un dossier avec le nom du projet (en minuscules, tirets au lieu d'espaces)
2. Faire des captures d'écran du code Arduino
3. Nommer les fichiers : `code-01.png`, `code-02.png`, etc.
4. Les screenshots seront automatiquement affichés dans le PDF

## Exemple

Pour un projet "Servo Moteur":
- Créer le dossier : `servo-moteur/`
- Ajouter les screenshots : `code-01.png`, `code-02.png`
- Ces images apparaîtront dans le PDF généré
